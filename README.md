# Tool Installation and Usage Guide

## Requirements

This tool only works on Linux. Please ensure you are using a Linux-based operating system.

## Prerequisites

You need to have Anaconda installed on your system. If you don't have Anaconda installed, you can download and install it from [here](https://www.anaconda.com/products/distribution#download-section).

## Installation

1. Clone the repository to your local machine:
    ```bash
    git clone https://github.com/idener/geass-and-metabolic-disassembler.git
    cd geass-and-metabolic-disassembler
    ```

2. Create and activate the conda environment using the `new_geass.yml` file:
    ```bash
    conda env create -f new_geass.yml
    conda activate new_geass
    ```

## Usage

Once the environment is set up, you can open the `All Protocols.ipynb` to see the usage of each protocol.
